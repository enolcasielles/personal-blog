## Welcome to my personal blog!

I've set myself the goal for 2024 to start creating content related to web development. The idea of this blog is to create articles about things I discover in my day-to-day as a web developer that I find interesting.

For the creation of this blog and the website in general, I forked [this repo](https://github.com/leerob/leerob.io) on GitHub, which is the [website](https://leerob.io/) of Lee Robinson, VP at Vercel and a clear reference in the world of web development. I also leave the [link](https://github.com/enolcasielles/personal-blog) to my repo with the changes made for the adaptation to my site. The project is deployed on Vercel and as a tool for creating content I use [https://mdxeditor.dev](https://mdxeditor.dev). The content of the articles is saved directly in the project files as markdown and is rendered at compile time, so it works as a completely static website without an external database. This solution is not the most ideal if the volume of articles starts to be high, but this will not be a problem today or in the medium term.
